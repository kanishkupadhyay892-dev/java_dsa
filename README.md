# Java DSA Repository

Welcome to my **Java Data Structures & Algorithms (DSA)** repository!  
This repo contains my practice codes and solutions for fundamental DSA topics, written in Java.

---

## 📂 Topics Covered
- **Arrays** → Basic operations, searching, reversing, second largest element, etc.
- **Strings** → Palindrome check, reverse, anagram, frequency count, and other common problems.
- **Sorting** → Implementation of sorting algorithms (Bubble Sort, Selection Sort, Insertion Sort, etc.).
- **Recursion** → Classic recursion problems (factorial, Fibonacci, string reversal, etc.).

---

## 🛠️ Tech Stack
- Language: **Java**
- IDE: Any Java-supported IDE (e.g., IntelliJ IDEA, Eclipse, VS Code)
- Compiler: JDK 8+
